# Release v1.0-arxiv

This is the frozen public artifact corresponding to the validated campaign reported in the preprint:

**Prefix Visibility Ratio: Quantifying Partial Observability in Carpet Bombing Detection**

The release contains the validated VANTA implementation, experiment configuration, task-adapted comparative implementations, published result files, verification scripts, and figure-regeneration material. It deliberately excludes ongoing or subsequent experimental branches.

The numerical verification target is the 2,160-run validated campaign with pooled counts TP=20,187, TN=10,634, FP=166, and FN=1,413.
